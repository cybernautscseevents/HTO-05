# AI / ML Service

The AI engine handling inference, LLM workflows, agent tools, and data processing.

## 🚀 Getting Started

```bash
# Set up Python virtual environment
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On Linux/macOS:
# source venv/bin/activate

# Install requirements
pip install -r requirements.txt

# Run service
python main.py
```

## 📂 Structure

- `agents/`: Autonomous agents and orchestrators
- `prompts/`: Structured prompt templates
- `pipelines/`: RAG pipelines and embeddings
- `models/`: Trained models or local weights (gitignored)
