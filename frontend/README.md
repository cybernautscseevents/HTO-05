# Frontend Application

The user interface layer of the project.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## 📂 Structure

- `src/components/`: Reusable UI components
- `src/pages/` or `src/app/`: Views and routes
- `src/services/` or `src/api/`: API client and backend communication
- `src/styles/`: Global stylesheets and design tokens
